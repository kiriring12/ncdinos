    엑셀 / 구글 시트로 일정·결과 가져오기

    시즌 일정을 엑셀이나 구글 시트에 정리해서 한 번에 가져올 수 있어요. 첫 줄은 제목 줄이고, 날짜 · 어웨이 · 홈 열은 꼭 필요해요. 지난 경기라면 점수, 승리투수, 패전투수, 홀드, 세이브 등을 같이 적어두면 함께 들어가요. 이미 같은 날짜·같은 대진의 기록이 있으면 비어있지 않은 칸만 덮어써서 갱신하고, 없으면 새로 추가해요.

    CSV에서 비어 있는 칸(예: 홀드, 세이브)은 체크 여부와 상관없이 기존 기록을 지우지 않아요. 점수·결과·취소는 항상 CSV 내용으로 갱신돼요.

    인식하는 제목: 날짜, 어웨이(원정), 홈, 어웨이점수, 홈점수, 결과(어웨이 승/홈 승/무), 구장, 어웨이선발, 홈선발, 승리투수, 패전투수, 홀드, 세이브, 어웨이MVP, 홈MVP, 취소(O), 취소사유. 팀 이름은 "두산", "LG", "KT", "키움"처럼 줄여 써도 돼요. 날짜는 2026-03-28, 2026.3.28, 3/28 모두 괜찮아요.

    기기 간 동기화 (GitHub 저장소 연동)

    이 페이지는 GitHub Pages 등 정적 사이트라 기본적으로 기록이 이 브라우저 안에만 저장돼요. 아래에 여러분의 GitHub 저장소 정보를 연결해두면, 입력한 기록이 저장소의 JSON 파일에 자동으로 저장되고 휴대폰·PC 어디서든 같은 정보를 열면 최신 기록을 불러올 수 있어요.

    토큰은 이 기기의 브라우저에만 저장되고 다른 곳으로 전송되지 않아요(깃허브 API 호출에만 사용). 각 기기에서 한 번씩 같은 값을 입력해두면 돼요. 토큰 발급: GitHub → Settings → Developer settings → Personal access tokens → 해당 저장소 Contents 쓰기 권한으로 생성.
